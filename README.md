# Coca-Cola HoReCa Forum 2026 — лендинг

Статический одностраничник: `index.html` + `css/style.css` + `js/app.js` + данные в `data/event.js`. Сервер не нужен.

## Обновить программу / спикеров / меню / адрес
Правится только `data/event.js` (обычный JS-объект, комментарии внутри). Фото спикеров и ведущего — в `assets/speakers/`, путь в поле `photo` (вертикальное 600×800, ≤150 КБ). Пустое `photo` → арка с инициалами. После правки для claude.ai-версии: `python3 build_artifact.py` и перепубликация.

Логотипы: `assets/logo/` — `horeca-forum-2026-white.png` (hero, вертикальный), `horeca-forum-2026-white-h.png` (шапка и футер), `favicon.png`. Исходники брендбука — `for-claude-design/logos-src/`.

Карта: по умолчанию Google Maps embed по запросу `venue.mapQuery`. Если организаторы пришлют точную ссылку-виджет (2GIS/Google «Поделиться → Встроить»), положить её в `venue.mapEmbed` — она перекроет запрос.

Дата/время старта отсчёта: `startsAt` в формате `2026-12-09T10:00:00+05:00` (смещение +05:00 = Алматы, не менять).

## Дизайн
Макет Claude Design (PDF 10.11) перенесён: токены в `:root` в начале `css/style.css`. С 11.11 шрифт — фирменная Helvetica Regular + Bold от организаторов (вместо Cormorant Garamond + Manrope из макета): `assets/fonts/*.woff2`, подмножество латиница + кириллица, по 30 КБ; исходные OTF лежат в `fonts-src/` и в репозиторий не попадают. Курсива в комплекте нет, слово «fusion» наклоняется браузером. Вернуть шрифты макета: переменные `--font-display` / `--font-text` и ссылка Google Fonts. Пакет для дизайна — `for-claude-design/`.

## Анимации
Вступление (один раз за сессию, любое касание пропускает; `?intro=1` — показать снова, `?slow=8` — замедлить для проверки):
1. Занавес — ткань на canvas (`drawCurtain` в `js/app.js`): складки сгребаются к кулисам, низ отстаёт от верха, после остановки покачивается.
2. В луче стоит золотая бутылка из логотипа, дрожит и взрывается: вспышка, два ударных кольца, пена и искры.
3. Частицы по силуэту бутылки собираются на её месте в логотипе и белеют, затем проявляется сама белая бутылка.
4. Три строки надписи (Coca-Cola, HORECA, FORUM2026) делают оборот на 360° волной.
Нажатие на логотип повторяет взрыв и вращение. При повторном заходе в ту же сессию занавеса нет, надпись делает один оборот.
Логотип для этого разрезан на слои `assets/logo/l-*.png` (одинаковый холст 1200×1085), центры слоёв записаны в `index.html` (`--ox/--oy`, `data-bx/by`). При замене логотипа слои нужно нарезать заново.
Прочее: лучи софитов, прожектор за курсором, золотая пыль, пословный заголовок, перелистывание цифр отсчёта, параллакс кулис, прорисовка таймлайна, наклон карточек спикеров. Всё отключается при prefers-reduced-motion.
После правок CSS/JS поднимайте версию `?v=` у ссылок в `index.html`, иначе браузер может склеить старый скрипт с новой разметкой.
