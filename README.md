## Обновить программу / спикеров / меню / адрес
Правится только `data/event.js` (обычный JS-объект, комментарии внутри). Фото спикеров и ведущего — в `assets/speakers/`, путь в поле `photo` (вертикальное 600×800, ≤150 КБ). Пустое `photo` → арка с инициалами. После правки для claude.ai-версии: `python3 build_artifact.py` и перепубликация.

Логотипы: `assets/logo/` — `horeca-forum-2026-white.png` (hero, вертикальный), `horeca-forum-2026-white-h.png` (шапка и футер), `favicon.png`. Исходники брендбука — `for-claude-design/logos-src/`.

Карта: по умолчанию Google Maps embed по запросу `venue.mapQuery`. Если организаторы пришлют точную ссылку-виджет (2GIS/Google «Поделиться → Встроить»), положить её в `venue.mapEmbed` — она перекроет запрос.

Дата/время старта отсчёта: `startsAt` в формате `2026-12-09T10:00:00+05:00` (смещение +05:00 = Алматы, не менять).

## Анимации
Вступление (один раз за сессию, любое касание пропускает; `?intro=1` — показать снова, `?slow=8` — замедлить для проверки):
1. Занавес — фрагментный шейдер WebGL (`FRAG` в `js/app.js`): складки сгребаются к кулисам, низ отстаёт от верха. Без WebGL — запасная 2D-отрисовка.
2. В луче стоит золотая бутылка из логотипа, дрожит и взрывается: вспышка, кольца, пена, искры, слетает крышка.
3. Логотип влетает одним оборотом на невидимый цилиндр, частицы собираются в белую бутылку прямо на изогнутой поверхности.
4. Цилиндр медленно вращается по часовой стрелке (15 с на оборот): на одной половине окружности логотип форума, на другой логотип CCI.

Цилиндр рисует один WebGL-холст (модуль `ring` в `js/app.js`): шейдер для каждого пикселя находит точку на поверхности и берёт цвет из текстуры логотипа. Ровное вращение рисуется около 30 раз в секунду. Без WebGL включается запасной вариант из 36 CSS-полос (`.ring3d__spin i`). Размер логотипа — `--lw`, радиус цилиндра в долях ширины — `--rk` у `.logo3d` (меньше `--rk` — логотипы занимают больше окружности, разрыв между ними меньше). Те же числа использует расчёт целей частиц (`wrap` в `burst`).

Лучи софитов неподвижны; пыль и прожектор двигаются только через transform/opacity и стоят, когда первый экран не виден. Всё отключается при prefers-reduced-motion.

Нагрузка в покое (M5, окно 1440×900@2x, замер ps по процессам Chrome): 18–21% одного ядра на первом экране, 4–5% при прокрутке вниз; в самом начале было 49%. Переход с 36 слоёв на WebGL сам по себе нагрузку не снизил (27,7% против 28,3%): дорога не отрисовка, а частота пересборки кадра. Помогли 30 кадров в секунду для вращения, неподвижные лучи и меньше пылинок.

После правок CSS/JS поднимайте версию `?v=` у ссылок в `index.html` и `menu.html`.
